# YouTube Clone

A responsive front-end clone of the YouTube homepage, built with HTML and CSS.

## Features
- YouTube-style header with search bar and icons
- Collapsible sidebar navigation
- Video grid with thumbnails, titles, channel names, and views
- Hover effects and clean layout

## Getting Started
```bash
git clone https://github.com/Gauthamshetty081/youtube-clone.git
cd youtube-clone
```
Then open `youtube.html` in your browser.

## Project Structure
```
youtube-clone/
├── icons/        # UI icons
├── pfp/          # Channel profile pictures
├── styles/       # CSS files
├── thumbnails/   # Video thumbnails
└── youtube.html  # Main page
```
